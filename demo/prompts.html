🤖 TalkScout, an AI-Powered Conference Session Finder

A tight 8-minute Data Exposed demo. Spec-driven build with GitHub Spec Kit, GitHub Copilot, the MSSQL VS Code extension, Prisma TypedSQL, and SQL Server 2025 native vectors.

🎬 Scenario Introduction

I am Carlos Robles, Principal PM for SQL developer experiences at Microsoft. Today I want to show you how I built TalkScout, a small app that helps me find dev conferences worth pitching my next talk to. I describe the topic in plain English. TalkScout returns the top 5 upcoming conferences whose CFP topics semantically match, with the CFP status visible at a glance.

"Every speaker has the same problem: where should this talk go? Listings sites organize events by date and region, not by topical fit. So I built TalkScout, end to end, in eight minutes of demo time. The whole project lives in VS Code. SQL Server 2025 stores the vectors natively. Prisma keeps my TypeScript clean. GitHub Copilot, with Spec Kit, drove the spec all the way to working code."

3:30 to 4:30 Marquee #1: Copilot inline in a SQL file

🔹 Step 5: Open searchEvents.sql, use Copilot inline

"This is the only SQL file you will see today. Eight lines. SQL Server 2025 has a native VECTOR(768) column type and a VECTOR_DISTANCE function. The query embedding arrives as a JSON array of 768 floats and is cast to a vector in place. Watch what GitHub Copilot does inside this file."

📌 Show: open prisma/sql/searchEvents.sql. Place cursor on the line after WHERE embedding IS NOT NULL. Type the comment below; Copilot inline-suggests the AND clause.

-- Filter to events whose CFP is still open today.

✅ Expected Copilot suggestion (accept with Tab):
AND cfpCloseDate >= GETDATE() AND cfpOpenDate <= GETDATE()

"That is GitHub Copilot, working inside a TypedSQL file, against SQL Server 2025 syntax. No plugin tax. No copy and paste. Just type a comment, get a suggestion."

5:00 to 5:30 Marquee #2: MSSQL extension

🔹 Step 7: MSSQL extension query editor, see the VECTOR column

"Let me prove the VECTOR column is real. The MSSQL extension for VS Code talks to my local SQL Server 2025 container. I'll connect, run a quick SELECT, and you can see the vector data sitting in the row."

📌 Show: click the MSSQL extension icon. Use the existing talkscout connection (sa, TalkScout!Demo2026). Open a new query window. Paste the query below. Press F5.

SELECT TOP 3
  name,
  topics,
  CAST(embedding AS NVARCHAR(80)) AS embedding_preview,
  VECTORPROPERTY(embedding, 'Dimensions') AS dims
FROM Event
ORDER BY name;

✅ Expected: results grid with three rows; dims = 768 on each; embedding_preview shows the first 80 chars of the vector.

Key takeaways:

  • Spec-driven development scales because the spec is on disk and reviewed before any code is written.
  • SQL Server 2025's vector support means you do not need a separate vector database for retrieval workloads at this scale.
  • Prisma TypedSQL is the cleanest way to use SQL Server's newest features from TypeScript without writing SQL strings in your app.
  • GitHub Copilot is a first-class citizen inside .sql files, not just .ts files.
