TalkScout

Semantic CFP finder for dev conferences. From spec to working app, end-to-end inside VS Code, with native vector search in SQL Server 2025.

What this stack gives you

An end-to-end semantic-search application inside VS Code, with no separate vector database, no cloud embedding API, and no SQL string literals in TypeScript. Five tools, each doing exactly one job, composed so a developer can go from "I want a CFP finder" to "it ranks events in three seconds" without leaving the editor.

Ollama (host)

Prisma 7

Schema-as-code. T-SQL stays in prisma/sql/; the call site reads as one line.
MSSQL VS Code extension
